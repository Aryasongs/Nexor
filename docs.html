Authentication

Every request needs an API key, passed as a bearer token in the Authorization header.

Header 
Authorization: Bearer nxs_your_api_key

For quick testing in a browser, you can also pass the key as a query parameter:

URL param (testing only) 
?key=nxs_your_api_key
Note — don't ship the query-param version in production code. Browser history and server logs can leak keys passed in URLs. Use the header in anything real.

GET /v1/pulses/:handle

Returns the Pulses posted by a given handle, most recent data as stored.

Path parameters

ParameterTypeDescription
handlestringThe creator's handle, without the @ symbol.

Request

cURL 
curl https://nexor-sparks-api-v2.sgursharn076.workers.dev/v1/pulses/sharanpooni \
  -H "Authorization: Bearer nxs_your_api_key"
JavaScript 
const res = await fetch(
  "https://nexor-sparks-api-v2.sgursharn076.workers.dev/v1/pulses/sharanpooni",
  { headers: { Authorization: "Bearer nxs_your_api_key" } }
);
const data = await res.json();

Response

200 OK 
{
  "username": "sharanpooni",
  "pulses": [
    {
      "creatorHandle": "sharanpooni",
      "createdAt": 1783017975595,
      "text": "..."
      // additional fields as stored
    }
  ]
}

Rate limits

Each API key is limited to 60 requests per minute. Going over returns a 429.

Errors

StatusMeaning
401Missing API key
403Invalid or inactive API key
429Rate limit exceeded — slow down and retry after a minute
502Upstream data source unavailable
404Route not found — check the path

Embed Pulses on your site

Drop this snippet anywhere on your page. It fetches Pulses for a handle and renders them as simple cards.

HTML + JS 
<div id="nexor-pulses"></div>
<script>
  const API_KEY = "nxs_your_api_key";
  const HANDLE = "sharanpooni";

  fetch(`https://nexor-sparks-api-v2.sgursharn076.workers.dev/v1/pulses/${HANDLE}`, {
    headers: { Authorization: `Bearer ${API_KEY}` }
  })
    .then(r => r.json())
    .then(data => {
      const container = document.getElementById("nexor-pulses");
      container.innerHTML = data.pulses.map(p => `
        <div style="border:1px solid #232937;border-radius:8px;padding:12px;margin-bottom:10px;">
          ${p.text || ''}
        </div>
      `).join("");
    });
</script>
Heads up — never expose your API key in client-side code on a public production site. For real deployments, proxy the request through your own backend so the key stays server-side.
